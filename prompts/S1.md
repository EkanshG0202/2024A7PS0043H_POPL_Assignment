# Q3 (S1) — Binary Tree Traversals (Scheme)

## Prompt 1 — Implement tree traversals and their output functions

Read the Q3/S1 requirements in the assignment. Implement the traversal logic and the two public output functions in `id_q3.rkt`:

- `(print-inorder tree)` prints the inorder list on one line.
- `(print-all-traversals tree)` prints inorder, preorder, and postorder on three separate lines, in that order.

The tree is either `()` or `(value left right)`. Traversals must visit the left subtree before the right subtree. Use clear recursive helpers as appropriate and reuse them rather than duplicating traversal logic.

Follow the assignment's restricted Racket built-ins strictly. The file must start with `#lang racket/base`, contain definitions only, and produce no output when loaded. Each public function's output must have exactly the required format and end with a newline.

Test the supplied t1, t2, t3 examples and the empty tree. Also test a single-node tree, left-skewed and right-skewed trees. Check exact traversal ordering and output formatting, not merely whether all values appear.

When the implementation and tests are satisfactory, commit:

`Implement Q3 tree traversals`

## Prompt 2 — Implement height and leaf counting

Implement the functionality for `(print-height-and-leaves tree)`, including any recursive helper functions needed.

Follow the definitions exactly:
- Height of `()` is 0.
- Height of a node is 1 plus the larger height of its left and right subtrees.
- A leaf is a node whose left and right subtrees are both empty.
- Empty tree has 0 leaves.

The function must display `(height leaf-count)` on one line and end with a newline.

Test the assignment examples, including t1, t2, t3, and the empty tree. Add a single-node tree, balanced tree, left-skewed and right-skewed trees, unequal subtree heights, and cases where one child is empty. Check height and leaf count separately to catch errors.

Review the code for prohibited built-ins, mutation, loops, or global state. Make only necessary changes and commit:

`Implement Q3 height and leaf count`
