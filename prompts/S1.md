## Prompt 1 — Tree traversals

Implement the tree traversal part of Q3 in `id_q3.rkt` according to the assignment.

Start by understanding the tree representation: an empty tree is `()`, while a non-empty tree is `(value left right)`. Implement the necessary recursive helpers and the following functions:

- `print-inorder` – prints the inorder traversal on a single line.
- `print-all-traversals` – prints inorder, preorder, and postorder, each on a separate line and in that order.

Try to keep the implementation simple and avoid unnecessarily duplicating traversal logic. Make sure the left subtree is always visited before the right subtree wherever required.

Stick strictly to the allowed Racket functions and the assignment restrictions. The file should use `#lang racket/base`, contain only definitions, and should not produce any output simply by being loaded.

Once implemented, test it using the given t1, t2, and t3 trees, as well as the empty tree. Also try a single-node tree and left- and right-skewed trees. Check that both the traversal results and the printed output are exactly correct, including newlines.

## Prompt 2 — Height and leaf count

Now implement the remaining functionality for Q3 in `id_q3.rkt`: `print-height-and-leaves`.

It should print the tree's height and number of leaves in the format `(height leaf-count)`, followed by a newline.

Keep the definitions consistent with the assignment:
- An empty tree has height 0 and 0 leaves.
- The height of a non-empty tree is 1 plus the greater of the heights of its two subtrees.
- A leaf is a node with both children empty.

Use recursive helpers wherever they make the code clearer, and make sure you handle empty trees correctly.

Test this function on the supplied t1, t2, t3, and empty-tree examples. Don't stop there—also check a single node, balanced and skewed trees, trees with unequal subtree heights, and nodes where only one child is empty. Verify both height and leaf count, since it's easy for one to be correct while the other is wrong.

Keep the implementation within the assignment's restrictions. After running your tests and fixing any issues, commit this part with:
